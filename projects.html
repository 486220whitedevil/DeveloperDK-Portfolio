SelfTechGyan

SelfTechGyan is an educational Android application focused on helping students learn technology through structured courses, notes and practical learning resources.

Project Overview

The application provides separate student and administrator experiences. Students can access learning content, while administrators can manage educational resources and application functionality.

Problem

Students often need learning resources, notes and technology courses in one organized platform. The project focuses on creating a simple, accessible and structured learning experience.

Solution

A dedicated Android application was developed with authentication, cloud-based data storage, notifications and separate student and admin functionality.

Technologies Used

Java Android Android Studio Firebase Authentication Cloud Firestore Firebase Cloud Messaging JavaScript HTML5 CSS3 Google Apps Script
KEY FEATURES

What the Project Includes

User Authentication

Firebase Authentication is used to provide secure user login functionality.

Learning Content

The application is designed around technology courses, notes and structured educational content.

Cloud Database

Cloud Firestore is used for storing and managing application data.

Notifications

Firebase Cloud Messaging enables application notification functionality.

Admin & Student Roles

Separate functionality is designed for students and administrators.

Backend Integration

The application integrates cloud services and Google Apps Script for backend operations.
